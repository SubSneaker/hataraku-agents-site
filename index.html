Contractors

Bring your own agents

Following the concept of BYOS (Bring Your Own Subscription), you can just start working with Hataraku Agents using the underlying coding agent you already use! Hataraku Agents is a visual layer connecting their work together.

To maximize the effectiveness of your Hataraku Agents office, we recommend using a program like T3 Code that can aggregate other subscriptions together!

Actions available from the office for each app
App Message Approve or deny Stop
T3 Code Yes Yes Yes
Claude Code When idle With a hook In a terminal
Codex When idle With a hook No
Hermes When idle No In a terminal
Cursor When idle With a hook No
Windsurf, AntigravityWatch and jump in. No No No

Hooks and connections are one click in Settings. Windsurf hasn't been tried on a real install yet.

  • Hire at the front desk. Give a new agent a task and watch them walk in.
  • Check in from your phone. Open your office anywhere with Tailscale.
  • Speaks your language. Available in 18 languages.

Server room

It stays on your machine

No cloud, no account, no telemetry. It only reads what your agent apps already keep on disk.

Local only
Runs on your computer. Only your own devices get in.
Read-only
It looks at your agents' files. It never touches them.
Redacted
Keys and tokens are masked before they reach the screen.
No LLM calls
The office doesn't call any AI. Your agents do the thinking.
One folder
Everything it saves lives in ~/.hataraku-agents.

Reception

Clock in

Clone the repo and you're two commands away. Node.js 23.6 or newer on macOS, Linux or Windows.

Signed in to the GitHub CLI? You get PR and CI signals too.

Start the office 
npm install
npm run dev

The office opens in your browser.

Just the demo 
npm run dev:web

Then open localhost:5317/?demo=1.

Daily use 
npm run build && npm start

Builds once, then runs on its own.
